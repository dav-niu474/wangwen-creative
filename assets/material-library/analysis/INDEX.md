# 拆文记录索引

> 存放单作品的拆文分析记录

## 目录结构

每次拆文完成后，在此目录下创建以作品名命名的拆文记录文件：

```
analysis/
├── INDEX.md          # 本文件
├── <作品名1>.md      # 单作品拆文记录
├── <作品名2>.md
└── ...
```

## 拆文记录模板
